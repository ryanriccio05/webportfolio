9/30/24

Hello and welcome to my school website! I enjoyed the concept of creating a Web Portfolio that keeps track of things in a stylized, efficient way, so for the homework assignment of creating a website I decided to create my own and expand upon this idea. The basic layout of this website came from a template on startbootstrap.com , and I grabbed a clock script online to display the time. Everything else is my own work, utilizing Bootstrap classes, CSS styling, images, and more to make things look nice!

I really enjoy working on this site, and even though this began as just a homework assignment I will definitely be using and updating this periodically. Any large updates I make will be listed here.
